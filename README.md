# SpendSight – Credit Card Analytics Dashboard

SpendSight is an interactive Power BI dashboard designed to analyze large-scale credit card transaction data. It provides deep insights into spending behavior, revenue patterns, and customer segments to support data-driven decision-making in financial domains.

---

## 📊 Key Features

- Visualized **650K+ credit card transactions** with interactive filters and drill-downs  
- Analysis of **revenue, interest earned, spending trends**, and customer behavior  
- Segmentation by **job role, education level, card type, and customer demographics**  
- DAX-powered KPIs for **total revenue, total transactions, interest**, and high-value customer groups  
- Data model optimized for fast insights using **DAX measures, star schema**, and Power Query transformations  
- Highlights actionable insights to identify **high-revenue segments** and optimize marketing or credit strategies  

---

## 🛠️ Technologies Used

- **Power BI** – Dashboard creation, data modeling, visualization  
- **DAX** – Calculated columns, KPIs, and custom measures  
- **Power Query** – Data cleaning and transformation  
- **SQL / CSV Source Data** – Backend data used for modeling  

---

## 📈 Insights Delivered

- Revenue contribution by customer category  
- Spending behavior across job roles  
- Interest generation grouped by card type  
- Education-wise customer segmentation  
- Identification of high-value customer cohorts  
- Trends revealing spending peaks and seasonal patterns  

---

## 🚀 How to Use

1. Download the PowerBI file    OR
2. Download or copy sql queries into your MySQL database  
3. Download the csv files  
4. Use DAX in PowerBI
5. Then you have the complete analytics
